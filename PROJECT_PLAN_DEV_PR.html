一、产品定位与边界

维度描述
外部定位AI 心理支持与自助干预助手
内部定位工作流驱动的心理健康支持平台：筛查 → 结构化对话 → 干预计划 → 跟踪 → 风险路由
核心价值早期识别症状模式 · 结构化支持 · 可测量的症状改善支持 · 安全边界与危机路由
产品边界不提供诊断、不替代精神科医生或心理咨询师、不处理急性高危用户深度干预

目标用户

  • 纳入：轻中度焦虑、低落、失眠、惊恐困扰、情绪失调或心理疾病早期预警信号的用户
  • 纳入：已有诊断但当前稳定，寻求结构化支持和自助工具的用户
  • 排除：活跃自杀意图、自伤计划、杀人意图、精神病性症状、严重躁狂等高风险用户（仅提供简短稳定化支持后路由）

高危处理原则

  • 仅提供简短稳定化语言
  • 立即建议就医、危机资源和现实支持联系方式
  • 不继续探索性咨询对话

三、对话模式与心理方法栈

对话模式

模式说明
support_mode情绪支持、反映性倾听、轻度结构化
assessment_mode筛查导向对话与症状澄清
intervention_modeCBT/ACT/DBT/行为激活引导

MVP 心理方法

  • CBT — 思维模式、症状维持与结构化练习
  • ACT — 接纳、认知解离、价值导向行动
  • DBT 技能 — 痛苦耐受与情绪调节
  • 行为激活 — 低动力与抑郁性减缓

交付格式

  • 每个方法配套策略卡
  • 触发条件、禁忌症与升级边界
  • 可复用练习模板
  • 按模式分的结构化对话 prompt

四、安全与风险框架

风险分级

级别说明
L0无明显风险
L1有困扰，无急性危险
L2关注升高，需更多评估
L3高风险，正常流程阻断
L4紧急风险指标，即时紧急指引

高危触发条件

  • 自杀或自伤表述
  • 杀人意图
  • 幻觉或妄想指标
  • 严重睡眠丧失或判断力受损的躁狂样表现
  • 强烈危险线索的失控感

后生成安全审查（正则红线）

safety_reviewer 节点对 LLM 输出施加硬正则约束，独立于 prompt 规则：

红线组说明状态
诊断语言"你有抑郁症""我诊断你得了…"等直接诊断表述已完成
越界承诺"我能治好你""你一定会好的"等承诺治疗/治愈/开药已完成
质询检测challenge_allowed=False 时拦截对抗性/追问性语言已完成
病理性归因"大脑扭曲感知""你的感知不真实"等将体验解释为感知扭曲已完成
主观体验否定"你看到的不存在""你听到的不是真的"等否定用户感知现实已完成
过度病理化标签"这是幻觉""这是妄想"等用临床术语标签化用户体验已完成

质询机制引用场景

challenge_allowed 默认为 False，仅以下场景允许质询：

场景触发关键词质询策略
矛盾检测"但是""可是""又""明明" / but, however, yet浮现张力，验证哪个更贴近真实体验
绝对化思维"一定""永远""根本""完全" / always, never, completely要求证据、例外、不同结果的标准
回避/最小化"随便""无所谓""不想说""算了" / whatever, not a big deal温和质疑回避，邀请一个具体例子
模式+矛盾/绝对化叠加"总是""每次" + 矛盾或绝对化先画序列再测断裂点
规划模式mode=planning明确约束与现实条件

始终禁止质询的场景：crisis 模式、high/critical 风险、assessment 模式、纯耗竭无矛盾/绝对化/回避、默认 engagement 阶段。

场景检测重点
